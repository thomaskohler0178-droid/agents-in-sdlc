**[GitHub Copilot CLI][about-copilot-cli]** を使うと、ターミナルで GitHub Copilot をエージェント型のコーディング アシスタントとして利用できます。コードベースを調査し、コードを生成し、コマンドを実行して、外部ツールに接続できます。すべてコマンド ラインから行えるため、グラフィカル エディターに切り替えずに作業を続けられます。

このワークショップでは、Tailspin Toys の一連のワークフローを進めます。

1. GitHub Codespaces でプロジェクトを準備し、Copilot CLI をインストールして、作業環境を確認します。
2. 星評価の変更を加えてブラウザーで確認し、最初のプル リクエスト (PR) を手動でマージします。
3. フィルタリングの issue から始め、Plan mode でアプローチを定義し、Autopilot mode で実装して、Interactive mode でレビューします。
4. リポジトリの指示を更新し、フィルタリング機能に適用します。
5. 既存の `quality-checks` スキルをカスタマイズして、プロジェクトのチェックを実行します。
6. Playwright Model Context Protocol (MCP) サーバーを追加し、ブラウザーでフィルタリング機能を確認します。
7. QA カスタム エージェントを作成して使い、要件、カバレッジ、検証結果をレビューします。
8. フィルタリングの変更全体を確認し、フィルタリングの PR に Agent Merge を使います。
9. コンテキスト、モデル、共有、cloud agent への任意の委任に使うスラッシュ コマンドを確認します。

ワークショップを簡潔に進めるため、星評価と、指示の更新、スキルの更新、QA プロファイル、テストを含むフィルタリングの 2 つの PR を作成します。フィルタリングと品質のワークフローでは 1 つの会話とブランチを共有するため、各ツールを学びながら前の作業を活用できます。

## 前提条件

このワークショップに参加する前に、次の条件を満たしていることを確認してください。

- [ ] 有効な **Copilot Student、Pro、Pro+、Business、Enterprise** プランを利用できる GitHub アカウント
- [ ] リポジトリと Codespace を作成する権限
- [ ] ターミナルまたはコマンド ライン操作の基本的な知識

> [!TIP]
> 有料プランを利用していない場合でも、認定を受けた学生は [GitHub Education][student-plan] を通じて GitHub Copilot を無料で利用できます。**Copilot Student** プランには、このワークショップで使うエージェント、MCP、コード レビュー、Copilot CLI の機能が含まれています。

> [!NOTE]
> Copilot Business または Copilot Enterprise を使用している場合は、管理者が Copilot CLI を有効にしていることを確認してください。
